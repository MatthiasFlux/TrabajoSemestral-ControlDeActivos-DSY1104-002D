# Control de Activos - Front End

Entorno de trabajo para el desarrollo Front End del caso semestral: **Control de Activos para Torre Central**.

## 📋 Descripción del Proyecto

Este proyecto corresponde al desarrollo de una interfaz web para la gestión y control de activos de una torre central. La aplicación permite a los usuarios interactuar con un sistema de registro y seguimiento de activos mediante una interfaz intuitiva y responsiva.

## 🛠️ Tecnologías Utilizadas

### Frontend
- **HTML5** - Estructura y marcado semántico
- **Bootstrap** - Framework CSS para diseño responsivo
- **CSS Personalizado** - Estilos propios del proyecto
- **JavaScript** - Validación de entradas y lógica interactiva

## ✨ Características Principales

- Interfaz responsiva adaptada a dispositivos móviles y de escritorio
- Validación de entradas del usuario mediante JavaScript
- Diseño accesible con botones de tamaño grande para interactividad táctil (RNF-02)
- Compatibilidad móvil mejorada (RNF-03)
- Navegación mediante sidebar colapsable
- Paleta de colores personalizada con énfasis en tonos celestes

## 🚀 Cómo Usar

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/MatthiasFlux/TrabajoSemestral-ControlDeActivos-DSY1104-002D.git
   ```

2. Navegar a la carpeta del proyecto:
   ```bash
   cd TrabajoSemestral-ControlDeActivos-DSY1104-002D
   ```

3. Abrir `index.html` en un navegador web

## 🎨 Personalización

El proyecto utiliza una paleta de colores personalizada:
- **Celeste principal**: `#4cc9f0`
- **Celeste oscuro**: `#00b4d8`
- **Fondo**: `#f4f6f9`
- **Sidebar**: `#212529`

Los estilos pueden modificarse en `styles.css` según sea necesario.

## 📱 Requisitos de Usabilidad

- **RNF-02**: Botones de gran tamaño (mínimo 48px de altura) para mejorar la interactividad táctil
- **RNF-03**: Compatibilidad móvil con diseño responsive

## 📝 Notas de Desarrollo

- La validación de entradas se realiza mediante JavaScript en el lado del cliente
- El sidebar es colapsable para optimizar el espacio en dispositivos pequeños
- Se utiliza Bootstrap como base del framework CSS
